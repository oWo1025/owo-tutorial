2 第一步：安装 Node.js

💡
什么是 Node.js？
你可以把它理解为一个"运行环境"。就像玩游戏需要安装 DirectX 一样，运行 OpenCode 需要 Node.js。
1 下载安装包
  1. 打开浏览器，访问 https://nodejs.org/
  2. 找到 "LTS" 版本（推荐），点击下载
2 运行安装包
  • 双击下载好的 .msi 文件
  • 一路点击 Next（下一步）
  • 在 "Tools for Native Modules" 这一步，不要勾选任何选项
  • 继续点击 Next 直到安装完成
3 验证安装
  1. 按 Win + R 打开运行对话框
  2. 输入 cmd 并按回车
  3. 在黑色窗口中输入以下命令：
命令提示符
node --version

如果看到类似 v20.11.0 的版本号，说明安装成功！

1 下载安装包
  1. 打开浏览器，访问 https://nodejs.org/
  2. 找到 "LTS" 版本，点击下载 macOS 安装包
2 运行安装包
  • 双击下载好的 .pkg 文件
  • 按照提示一路点击"继续"和"安装"
  • 输入你的电脑密码完成安装
3 验证安装
  1. 打开"终端"（在"应用程序" → "实用工具"文件夹里）
  2. 输入以下命令：
终端
node --version

看到版本号就说明成功了！

3 第二步：安装 OpenCode

1 打开命令提示符
  1. 按 Win + R 打开运行对话框
  2. 输入 cmd 并按回车
  3. 会打开一个黑色的窗口（命令提示符）
2 执行安装命令

在黑色窗口中，复制以下命令，然后粘贴到窗口中：

命令提示符
npm install -g opencode-ai
📋
如何复制粘贴？
• 复制：选中上面的命令文本，按 Ctrl + C
• 粘贴：在命令提示符窗口中，按 鼠标右键 即可粘贴
• 然后按回车键执行命令
3 等待安装完成

你会看到类似这样的输出：

输出示例
added 1 package in 15s
4 验证安装是否成功

输入以下命令，然后按回车：

命令提示符
opencode --version

如果看到版本号（例如 1.1.50），说明安装成功！

1 打开终端
  1. 按 Command + Space 打开 Spotlight 搜索
  2. 输入 "Terminal" 或 "终端"
  3. 按回车打开
2 执行安装命令

输入以下命令，然后按回车：

终端
curl -fsSL https://opencode.ai/install | bash
3 验证安装
终端
opencode --version
✅
安装完成！ 现在你已经成功安装了 OpenCode，接下来让我们马上体验一下！

5 进阶：连接其他AI模型 进阶

如果你想使用更强大的AI模型（如Claude、GPT等），可以按照以下步骤配置。

1 准备API密钥

你需要从AI服务商获取API密钥：

服务商 模型 获取方式
Anthropic Claude https://console.anthropic.com/
OpenAI GPT https://platform.openai.com/
DeepSeek DeepSeek https://platform.deepseek.com/
阿里云 通义千问 https://bailian.console.aliyun.com/
2 创建配置目录

Windows用户：

命令提示符
mkdir %USERPROFILE%\.config\opencode

Mac用户：

终端
mkdir -p ~/.config/opencode
3 创建配置文件

配置文件位置：

  • Windows：C:\Users\你的用户名\.config\opencode\opencode.json
  • Mac：~/.config/opencode/opencode.json

使用记事本或其他文本编辑器创建 opencode.json 文件，内容如下（以阿里云百炼为例）：

opencode.json
{ "$schema": "https://opencode.ai/config.json", "provider": { "alibaba": { "npm": "@ai-sdk/anthropic", "options": { "apiKey": "你的API密钥", "baseURL": "https://dashscope.aliyuncs.com/compatible-mode/v1" }, "models": { "qwen-max": { "name": "Qwen-Max", "attachment": true } } } }, "model": "alibaba/qwen-max" }
⚠️
注意：把 "你的API密钥" 替换成你从阿里云百炼获取的真实 API Key。
4 重启OpenCode

配置完成后，关闭当前OpenCode，重新启动即可使用新的模型。

终端
opencode

6 常见问题及解决方案

❓ Windows 系统提示"禁止运行脚本" ▼

错误现象：

错误信息
无法加载文件 C:\Program Files\nodejs\npm.ps1，因为在此系统上禁止运行脚本。

解决方案：

  1. 以管理员身份运行 PowerShell
  2. 输入以下命令：
    PowerShell
    Set-ExecutionPolicy RemoteSigned
  3. 按回车，然后输入 Y 确认
  4. 重新执行安装命令
❓ 提示"权限不足"或"Permission denied" ▼

解决方案：

  • Mac用户：在命令前加 sudo
    终端
    sudo npm install -g opencode-ai
  • Windows用户：以管理员身份运行命令提示符
❓ 安装后输入 opencode 提示"命令未找到" ▼

解决方案：

  1. 关闭当前命令行窗口
  2. 重新打开一个新的命令行窗口
  3. 再次尝试输入 opencode
❓ 网络问题导致安装失败 ▼

解决方案：

使用国内镜像源安装：

终端
npm install -g opencode-ai --registry=https://registry.npmmirror.com
